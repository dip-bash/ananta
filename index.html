Scrollable tiling terminal

ananta

The endless terminal multiplexer

A scrollable tiling multiplexer built in Go. Panes live in columns on an endless horizontal strip, gliding smoothly into focus.

Install

curl -sSL https://raw.githubusercontent.com/dip-bash/ananta/main/install.sh | bash

01

Infinite Horizontal Canvas

Panes live in columns on a scrollable strip. The viewport glides smoothly to whatever has focus, so nothing is ever cramped into a fixed split.

02

Animated Overview Mode

Zoom out for a bird's-eye view of every workspace and column, then jump straight to where you need to be.

03

Vim-Style Copy Mode

Modal movement keys, block and line visual selections, and OSC 52 system clipboard support.

04

Configurable Status Bar

Built-in CPU, MEM, Net and Battery metrics, plus your own shell command widgets.
