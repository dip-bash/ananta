ananta

A Niri-inspired terminal multiplexer

Ananta is a scrollable, tiling terminal multiplexer written in Go. Its columns form a horizontal canvas inspired by tiling-window-manager workflows. Move between workspaces, keep long-running programs alive across SSH disconnects, and manage shells, editors, builds, and logs from one keyboard-driven interface.

WORKFLOW

A tiling-window workflow, built for the terminal

Ananta brings a Niri-inspired horizontal layout to terminal work. It is designed for people who spend their day in shells, editors, remote servers, and command output—not for managing a collection of cramped, fixed terminal splits.

Remote administration over SSH

Run long-lived commands in a persistent Ananta session on a remote machine. If your terminal closes or the SSH connection drops, the background session can keep its programs running so you can reattach later.

A wider canvas for focused work

Move horizontally between task-focused columns and workspaces. The layout takes inspiration from tiling window managers such as Niri while keeping the workflow inside your terminal.

Development and operations in one place

Keep an editor, test command, build process, log tail, or system monitor in its own pane. Use keyboard navigation, per-pane scrollback, and status-bar widgets to move between tasks.
